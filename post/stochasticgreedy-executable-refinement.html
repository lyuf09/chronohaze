从一套框架到真正会运行的随机算法：StochasticGreedy 的 executable refinement

Feier Lyu · 首次发布于 2026年10月3日 · 更新于 2026年10月25日 · 约 2 分钟

Isabelle/HOL · StochasticGreedy · 未发表扩展

StochasticGreedy 可执行精化的简短进展摘要：已完成概率语义连接与期望近似证明，并建立预言机调用次数界。

本页介绍的是已发表 AFP 条目之后继续开展的扩展工作。最新实现尚未公开；下方 GitHub 链接指向较早的公开版本。

已完成的进展

2026 年 AFP 正式发表的条目覆盖经典贪心算法与经验证的有状态惰性贪心变体。这里介绍的 StochasticGreedy 是发表后继续开展的未发表扩展。

扩展已将可执行采样器与抽象概率模型连接起来，并将单步期望增益分析用于完整运行的期望近似保证；同时证明了几乎必然终止、输出可行性与预言机调用次数界。具体的 weighted-coverage 实例支持精确离散计算与 SML 代码生成。

随机语义的适用范围

期望近似保证采用理想随机位语义。PCG 部分证明的是实现优化前后保持同一随机流和执行行为，并不证明 PCG 输出等同于独立公平随机位。

当前工作与公开材料

当前重点是实现改进、实验评估与论文范围整理。完整的期望实现成本分析仍是可能的后续工作。详细证明、最新源码与完整实验材料目前按需定向交流；正式发布时将整理有明确版本与复现入口的发布包。

From a Framework to a Randomized Algorithm That Actually Runs: Executable Refinement of StochasticGreedy

Feier Lyu · Originally posted October 3, 2026 · Updated October 25, 2026 · ~2 min read

Isabelle/HOL · StochasticGreedy · Unpublished extension

A brief progress summary of executable StochasticGreedy: the probability-semantics connection and expected approximation guarantee are established, together with oracle-cost bounds.

This page describes ongoing work extending the published AFP entry. The latest implementation is not yet public; the GitHub link below points to an earlier public version.

Completed progress

The formally published 2026 AFP entry covers classical greedy and a verified stateful lazy-greedy variant. The StochasticGreedy work described here is an unpublished extension developed after that entry.

The extension connects executable sampling to the abstract probability model and transfers the one-step expected-gain analysis to the expected approximation guarantee for the complete run. It also establishes almost-sure termination, output feasibility, and oracle-cost bounds. A concrete weighted-coverage instance supports exact discrete computation and SML code generation.

Scope of the random semantics

The expected approximation guarantee uses ideal random-bit semantics. The PCG results establish that implementation optimizations preserve the same random stream and execution behavior; they do not establish that PCG output is equivalent to independent fair random bits.

Current work and public materials

Current work focuses on implementation improvements, experimental evaluation, and defining the paper scope. A full expected implementation-cost analysis is a possible next step. Detailed proofs, the latest source, and the complete experimental materials are currently shared for focused discussions on request. A formal release will provide a clearly versioned package and an entry point for reproduction.
